Importing Data from CSV

Open Settings > Data Management > Import Data to bring workouts and body records from a CSV file into LiFTY. Records from other apps, or from a notebook or spreadsheet, can be imported too if you shape them into the format below. Importing is free.

Templates

  • Simple format (date, exercise, weight, reps, number of sets)
  • Body records
  • Example of a file exported by LiFTY (all columns)

Minimum columns

For workouts, the four columns Date, Exercise, Weight, and Reps are enough. Every other column is optional.

Date,Exercise,Weight,Reps,Number of sets
2026-10-14,Bench Press,60,10,3
2026-10-14,Dumbbell Curl,12,10,3
2026-10-16,Squat,80,8,4
  • Rows with the same date become one workout (if there's a start time or session ID column, that's used instead).
  • Writing 3 in "Number of sets" creates three sets with the same weight and reps. One row per set works too.
  • For bodyweight exercises, leave Weight empty. Weights with a unit, such as "60kg" or "135lbs", are read as well.
  • Headings can be in English or Japanese, in any order. For headings we can't recognize, you choose what each column is during the import.

LiFTY's export also includes columns such as Session ID, Start (ISO 8601), and End (ISO 8601). Importing it as is restores your records exactly.

How the import works

  1. Tap "Choose File" and pick a CSV (any file in the iPhone's Files app).
  2. If some headings aren't recognized, choose what each column is.
  3. Check the period, counts, and any rows that couldn't be read.
  4. Choose which LiFTY exercise each exercise in the file should be recorded as. Exercises with the same name are matched automatically; ones that aren't found can be added as new. Different units are converted.
  5. If the file has locations, choose them (the free plan allows up to 2 locations).
  6. Review and tap "Import".

No duplicates

Workouts with the same date and start time (or body records with the same date and item) that are already in LiFTY aren't imported. Importing the same file twice won't duplicate your records.

Undo

After importing, "Undo Last Import" removes everything from that import, including new exercises and locations. Only the most recent import can be undone.

Encoding and saving

CSV files in UTF-8 (with or without BOM) and Shift_JIS can be read. If you make the file in a spreadsheet app, save it in CSV format.
